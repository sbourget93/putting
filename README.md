# Putting

This is an app to encourage disc golfers to practice their circle 1 putting every day.

Each day the app will prompt users to take 5 putts in a row at each distance from 12 feet to 33 feet.
The app is intentionally scoped to just this daily "test" of 110 putts.

The daily putts are the only active feature of this app, but the stored data allow users to:
- View any player's entire putting history, including a graph of putting percentage over time to observe improvement.
- View daily/monthly/all-time leaderboards.
- Compare two players' putting percentage by distance on the same graph.
