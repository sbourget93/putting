# Putting

This is an application to help me and my friends test and track our disc golf putting ability from C1X (33 feet and in excluding tap ins). 

Each day the app will prompt us to take 5 putts in a row from each distance from 12 feet to 33 feet.
The app is intentionally scoped to just this daily "test" of 110 putts.

Each user's putting history and statistics are publicly viewable.
