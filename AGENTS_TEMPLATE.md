# Agent Instructions
- This file applies only to the template repo. If no file called `.is_template` is present at the repository root, disregard everything in the rest of this file.
- The code in this repository is still in its early stages. Treat documentation as though it describes intended future state, not necessarily current state.
- Keep code in this repository generic. Anything specific to a single application belongs in the fork, not the template.
- Instructions and documentation in this repository will refer to "this app" so that they make sense to future forkers.

# Repository Description
This repository is a forkable application template spanning infrastructure, frontend, and backend. It provides the generic components most apps need, so a new project can start on app-specific work instead of boilerplate.
